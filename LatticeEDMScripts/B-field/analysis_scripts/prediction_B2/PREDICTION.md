# B2 — Twinleaf MS-1L 内の低周波ノイズ予測（測定前予言）

> 2026-07-04 作成。**新シールド到着前の定量予測**であり、受け入れ測定との「予測 vs 実測」対で使う。
> 計算の実体: `predict_ms1l_noise_budget.py`（同ディレクトリ。数値は `b2_summary.{md,json}` に自動出力）。
> 入力の出典: Twinleaf product page・QuSpin 仕様・Lee & Romalis 2008・実測は `analysis/` 配下。

---

## 0. 問いと答え（TL;DR）

**問い**: 簡易シールドで実測した低周波超過（0.05 Hz で ~500–600 fT/√Hz ＝ Lattice 目標 50 fT/√Hz の10倍）は、MS-1L に移すとどうなるか。

**答え（3シナリオの予言）**:

| bench 1/f 超過の正体 | MS-1L 内の 0.05 Hz 予測 | 目標 50 fT/√Hz |
|---|---|---|
| **E: 外来磁場のリーク** | **78 fT/√Hz**（34–224） | 当落線上（中央値は僅かに超過） |
| **M: 簡易シールドの磁化ドリフト** | **48 fT/√Hz**（34–91） | ぎりぎり合格（中央値） |
| **S: QZFM センサー自身の 1/f** | **~613 fT/√Hz（不変）** | 不合格のまま |

- **どのシナリオでも「MS-1L で余裕をもって 50 を下回る」ことはない**。E/M の場合の律速は外来ノイズではなく **MS-1L 自身の μ-metal 磁化ノイズ**（白色 16 fT/√Hz 仕様の 0.05 Hz への 1/√f 外挿 ≈ 34–89 fT/√Hz）。
- **白色床（3–10 Hz）は bench より悪化する予測**: 11.5 → **17.5–22 fT/√Hz**（GUI 経路）。シールド自己ノイズ 16 fT/√Hz がセンサー（7–15）を上回るため。これ自体が受け入れ試験の合否数値になる。
- **MS-1L 到着後の最初の長時間測定（≥2 h）それ自体が、bench 1/f の起源判定実験になる**（§4 判定樹）。1台では E と M は分離できないが、「S か否か」は一発で決まる。

## 2. モデル（振幅スペクトル密度・二乗和）

```
B_pred²(f) = B_leak²(f) + B_shield²(f) + B_sensor² [+ B_daq²  ※DAQ経路のみ]

B_leak(f)   = B_excess_bench(f) × S_bench / S_MS1L        （シナリオ E のみ）
B_shield(f) = 16 fT/√Hz × √(1 + f_magn/f)                 （渦電流白色＋磁化 1/f）
```

- `B_excess_bench` = bench 実測からセンサー律速の白色床 11.5 fT を二乗差し引いた超過分。
- シナリオ M は `B_leak=0`（bench の超過が bench 固有の磁化ドリフトなら、デガウス済み MS-1L には持ち込まれない）。シナリオ S は「センサーが持ち歩く」ので bench 実測がそのまま再現。
- 実際は混合があり得る（§5）。

## 4. D2 受け入れ測定への判定樹（この予測の使い方）

**白色床（3–10 Hz, GUI 記録で可）**:
- 17–25 fT/√Hz → 公称どおり（シールド自己ノイズ 16 fT を初観測＝2台クロスの理想標的を確認）
- ~12（bench 同等）→ 実物が公称より静か or **利得校正ズレ** → 内蔵コイル 69/130 nT/mA で校正①を先に
- ≫25 → 接地ループ・コイル線の拾い・デガウス不良を疑う

**0.05 Hz（≥2 h 記録, §6）**:
- **~500–600 → シナリオ S 確定**: 低周波はセンサー律速。シールド側への投資（シェイキング等）は 0.05 Hz には無効 → B3 の最優先提案は **2台クロススペクトル**（と E 反転帯域の再考）
- **~35–90 → E/M（実磁場/磁化）確定**: bench の超過は本物だった。MS-1L でも目標は当落線上で、**律速は MS-1L 自身の磁化ノイズ** → B3 は MS-1LF（フェライト, ~1 fT 白色）・本番大型シールドの最内層材料の議論へ
- **中間（~100–300）→ 混合**: 分解には 2台クロス（A5/P5）＋デガウス前後比較（C1）

## 5. 限界・注記

1. **f_magn が最大の不確かさ**: MS-1L の壁厚・材料 tanδ は非公開で、0.05 Hz の shield 項は 34–89 fT/√Hz と 2.6 倍振れる。到着後、**内蔵コイルを使わない静置長時間 ASD の 0.1–1 Hz 帯の形**から f_magn を実測でフィットできる（この予測の最初の答え合わせ）。前提として MS-1L は受け入れデガウス済み・Field Zero 済み・±1 V 窓内とする。
2. **仕様の条件が一部未確認**: Twinleaf の 16 fT/√Hz は帯域・条件不明（product page はグラフのみ、白色＝渦電流由来と仮定）。QZFM の <3 Hz 自己ノイズも仕様外なので、低周波センサー項は白色外挿（楽観側バイアスの可能性）。
3. **シナリオは混合し得る**（表は純粋ケースの限界値）。軸間・交差結合も無視した（S_yz 型の結合は bench の S bracket に実質吸収）。
4. bench シールドの素性（Collings 機か別物か）は**未測定のまま**で、S_bench bracket はその仮説に依存する。

## 6. 検証測定の統計設計（最短プラン）

- 0.05 Hz を Welch で見るには **セグメント ≥400 s**。**2 h 記録**（GUI 203 Hz で ~1.5M 点）→ 50% overlap で ~35 セグメント → ASD 精度 ~±9% ＝ シナリオ判別（613 vs 78）には桁余裕。**最低 30 min でも判別可能**（±20% 程度）。
- 記録経路: 低周波だけなら **GUI デジタル（量子化なし・非同期で可）が最簡**。アナログ経路なら fs=1200・±1 V・（必要なら）オーバーサンプリング＋間引き。
- 白色床の照合は同じ記録の 3–10 Hz を使う（追加測定不要）。
